# @apatureai/verdict-types

The shared contracts for [verdict](https://github.com/apatureai/verdict): the
`critique()` and capture interfaces and the `Finding` / `Critique` / wire-result
types that every other package speaks. Types only — no runtime behavior.

```ts
import type { Finding, Viewport, EngineReviewResult } from "@apatureai/verdict-types";
```

See the [repository README](https://github.com/apatureai/verdict#readme).

> Status: 0.1.x, API may still move. Requires Node >= 24.
